# ドラムロール＆表彰曲

## [アプリを開く](https://code4fukui.github.io/drumroll/)

GitHub Pagesで公開中です。

ドラムロールの後に、表彰曲リストからランダムに1曲を再生するWebアプリです。

## 使い方

- 「再生」を押すとドラムロールを開始し、その終了後に表彰曲を再生します。
- 「停止」を押すと約3秒かけてフェードアウトします。
- マスター、ドラムロール、表彰曲の音量を個別に調整できます。
- チェックボックスでドラムロールと表彰曲をそれぞれ有効・無効にできます。
