# drumroll

ボタンをタップするだけでドラムロールの効果音を再生できる、ミニマルなWebアプリケーションです。

## デモ

**https://github.com/code4fukui/drumroll

## 特徴

- **シンプルなインターフェース**: 音の再生と停止を行う、大きめのボタンが1つだけの構成です。
- **レスポンシブデザイン**: 画面サイズを問わず機能する、すっきりとしたダークテーマのレイアウトです。
- **軽量**: 外部ライブラリを使用せず、プレーンなHTML、CSS、JavaScriptのみで記述された自己完結型のアプリケーションです。

## 使い方

1. Webブラウザで[デモリンク](https://code4fukui.github.io/drumroll/)を開きます。
2. ボタンをタップしてドラムロールを再生します。
3. もう一度ボタンをタップすると音が停止します。

## クレジット

このプロジェクトでは、Freesound.orgの無料効果音を使用しています。

- **Sound:** [Long Snare Drum Roll with Cymbal Crash.mp3](https://freesound.org/people/MissloonerVoiceOver255/sounds/569113/) by MissloonerVoiceOver255
